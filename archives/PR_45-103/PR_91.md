## Original description

## User-approved global visual palette
- **ALL RED action buttons**, regardless of label or Lab, should be electric red **#E60000**, white bold text, 3dp gold border.
- **ALL GREEN action buttons**, regardless of label or Lab, should be neon green **#39FF14**, black bold text, 3dp gold border.
- Start and Exit buttons still receive their prescribed colors based on localized semantic labels even if their legacy background is neutral.
- Preserve blue, gold, neutral, status/measurement visuals and non-button components untouched. This is about **button backgrounds**, not diagnostic colors.
- Allow readable multiline labels, at least 56dp high, 15sp bold type, matching horizontal red+green button pairs with equal width and adaptive height.

## Implementation
- Introduce centralized `GelActionButtonStyle` to discover semantic Start/Exit labels **and** inspect programmatic button fill colors, background tints, nested ripple/drawable resources, including Greek/English. HSV classification explicitly excludes yellow, orange, cyan and translucent decoration. Idempotent calls from `GelButton.onAttachedToWindow`, `GelButtonLayout.fitDialog` and shared `GELAutoActivityHook.onWindowFocusChanged`.
- Retain a gold ripple effect on styled buttons; no `OnClickListener` or diagnostic logic changes.
- Convert three shared red XML button shapes to new approved red and gold border.
- Fix Lab 3 original red from #8B0000 to #E60000; correct independent, equal-width wrap-content Start/Exit controls. Lab 4 uses the same red, green and dimensions.
- Add Robolectric tests for Greek/English labels, arbitrary red/green actions (including ΝΑΙ/ΟΧΙ), old shades, neutral colors, horizontal sizing and click-listener preservation.

## Risk and QA
This affects a widely shared UI component. Require source build + Robolectric green, Android 11 phone / Android 16 tablet screenshots in Greek and English, font scaling, dialogs and all 31 Labs. Confirm no red/green button loses touch response, text readability, meaningful enabled/disabled states or its previous action. Detect any custom non-GEL or dynamic dialogs not covered during QA.
**No merge to main** until full QA and real-device acceptance. Draft stacked on #90.
