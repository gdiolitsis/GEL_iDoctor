## Additional P0/P1 defects fixed during actual source audit (2026-11-11)
- **P0 inaccessible picker:** Apple declaration dialog created iPhone/iPad buttons without click listeners. Both now open the correct family selector and dismiss the parent dialog first.
- **P0 DEMO/report contamination:** Demo now executes as UI-only simulation, skips all GELServiceLog report sinks and restores any previous imported panic state after the simulation. No demo results become report evidence.
- **P1 destructive import cancellation/error:** Replacement no longer deletes prior validated logs when the SAF picker opens; cancel, oversize, unsupported or unreadable ZIP retains the previous session; successful replacement commits atomically.
- **P1 ZIP accounting/safety:** New pure-Java ApplePanicArchiveReader with bounded entries, bytes and combined output; rejects oversized unrelated entries too. Number of supported .ips/.log entries is counted rather than miscounting one ZIP as one panic incident.
- **UX evidence honesty:** Greek Apple family/model popup localized; guide no longer suggests that more logs guarantee diagnostic accuracy or that import constitutes direct physical iPhone testing.
- **New automated coverage:** 8 deterministic JUnit ZIP cases and per-emulator `tools/ci/apple_ui_audit.py` for 9 modern model selections, Duo Touch ID, iPad family selector, 8 lab navigation and demo UI on API 30/36 in Greek/English.
