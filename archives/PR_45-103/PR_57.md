## Source-level iPhone / Apple-mode QA before the unified Turbo Labs APK

**Urgent cross-platform accuracy gate, not a release approval.** The owner requested an explicit audit of the iPhone reference model cards and all eight panic-log labs before packaging the new GEL iDoctor APK.

**Verified source findings (7 groups):**
- Uncalibrated seven-rule signature pack makes HIGH confidence / NAND-RAM-PMIC chip-failure claims or suggests board repair from keyword matches. Parser now returns `UNVERIFIED` keyword hypotheses and technician corroboration, not automatic repair.
- Lab8's arbitrary subtractive "device stability /100" and hardware/software "probability" retired; replaced with imported panic counts, scoped domain hints, model/iOS limits and unknown root cause.
- ZIP importer was closing the parent ZIP stream while processing an individual file; now bounded reading preserves parent entry lifecycle and recognizes ZIP magic from file providers with opaque names.
- Pure candidate gating rejects generic "thermal"/"jetsam"/"incident" text as proof of a panic.
- Labs5–7 only count actual eligible panic blocks, not wrapper/header fragments, and no longer treat repeated keyword classes as confirmed failed hardware.
- iPhone model lookup no longer maps unknown variants such as **iPhone 16e** to iPhone 16; iPad mini unknowns no longer map to mini 6. Added modern *model choices* while showing a warning when detailed technical reference specs remain unverified; existing exact model cards preserved.
- Explained that panic log structure and evidence vary by Apple model and iOS release.

**Changed files:** `IPSPanicParser.java`, `IPhoneLabsActivity.java`, `ApplePanicEvidencePolicy.java`, `iPhoneSpecs.java`, `iPadSpecs.java`, `AppleSpecs.java`, `MainActivity.java`, 2 JUnit files, QA document.

**Tests:** 28 JUnit cases **authored, not yet confirmed executed**; 24 device/fixture/export scenarios **planned, not executed**. Details: `docs/qa/APPLE_IPHONE_PANIC_AND_MODELS_ACCEPTANCE_2026-11-09.md`.

**Mandatory remaining gates:** Exact-SHA Android compile/unit tests, Greek/English API30/API36 emulator and UI tests, real anonymized Apple `.ips` fixtures, ZIP multi-entry and oversize tests, model-card source verification, report/PDF and data privacy review. No comprehensive iPhone hardware validation claimed; user-selected newer models without verified specs show an explicit limitation.
