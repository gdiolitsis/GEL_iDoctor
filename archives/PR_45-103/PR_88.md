## Purpose
Real-device Lab 6 visual checks should not depend on the user's low ambient display-brightness setting. The existing `DisplayProTestActivity` already requested maximum window brightness (`1f`) but did not explicitly restore the incoming request when presentation stopped.

## Narrow correction
- Before presenting patterns, **remember the window's current `screenBrightness` request**, including `BRIGHTNESS_OVERRIDE_NONE` (-1) for ordinary Android/system-controlled brightness.
- Temporarily request `BRIGHTNESS_OVERRIDE_FULL` (1f) **only within the Lab 6 visual test Activity**. Existing OLED warning remains and is clarified in Greek/English: temporary override, no user settings changed, possible panel stress.
- Explicitly restore the original value when the 8-step × 3-cycle test finishes (before the final user dialog), and on cancel, back navigation, Activity pause, Activity destroy and successful answer.
- Release `FLAG_KEEP_SCREEN_ON` after the patterns or any test termination. Prevent indefinitely keeping the display on while waiting at the questionnaire.
- Do not touch `Settings.System.SCREEN_BRIGHTNESS`, `SCREEN_BRIGHTNESS_MODE`, `WRITE_SETTINGS` or any other persistent preference; automatic-brightness mode is left intact.
- Do not modify pixels, steps, durations, scope, UI language, manual answers, or Lab 6 result/log policy.

## Evidence caveat
Window `screenBrightness` is a **request**, not measured luminance (nits). OEM/thermal/power restrictions may apply, so do not report a measured brightness or calibrated colour fidelity.

## Required acceptance before main
- Android 11 phone / Android 16 tablet, Greek/English, source-built QA; confirm visual patterns and accessibility.
- On Xiaomi with automatic brightness **on and off**: note initial user brightness, start the test, verify temporary increase and recovery on (a) normal completion, (b) Exit, (c) Android back and (d) interruption/background. Confirm the system slider and auto mode never change.
- Verify touch grid 96/96 and Lab 6 logging unaffected.
