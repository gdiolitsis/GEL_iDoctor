## Phase A — source parity and lifecycle, no per-Lab APK

Base `4947eec3adbcd9d626204584113a8985a19768e8`; exact source head `3ac78db9599b6ca595aace6a9c4e441ced39fa74`; restored main / protected backup / Play untouched.

Legacy Lab 9 enumerated sensor names and falsely pronounced the entire suite healthy. Current source **already** retains all sensor enumeration, accelerometer, gyroscope, light and proximity, with a 5-second real event stream and explicit scope limits. This change closes an additional lifecycle defect:
- A five-second SensorEvidenceProbe no longer remains subscribed when the Activity is paused/backgrounded; `Handle.cancel()` unregisters its listeners and quits its worker.
- A session-generation `SensorRunGate` prevents stale callbacks from updating UI or clearing the state of a later run; duplicate concurrent sessions are refused.
- Preserve all sensor-event details (valid count, invalid count, variation axes, timestamp order); no automatic physical-chip health certificate.
- Keep legacy `SensorEvidenceProbe.sample(Context, Callback)` wrapper, add cancellable overload rather than removing other existing clients.
- Four JUnit tests for cancellation, stale-callback generations, normal completion and duplicate starts.
