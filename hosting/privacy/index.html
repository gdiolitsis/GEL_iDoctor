GEL iDoctor – Privacy Policy

Effective date: October 24, 2026

1. Overview

GEL iDoctor is a device diagnostics and maintenance application. It provides user-facing tools for inspecting Android device status, hardware, sensors, connectivity, installed applications, storage, performance and other diagnostic information.

2. Installed application information

GEL iDoctor may inspect the applications installed on the device in order to provide app-level diagnostics and maintenance functions, including identifying applications that may contribute to storage, cache, performance or resource-usage issues.

Because the set of installed applications is different on every device and cannot be known in advance, GEL iDoctor uses Android's QUERY_ALL_PACKAGES permission for this core diagnostic functionality.

Installed-application inventory is used for device diagnostics and maintenance. It is not sold or shared for advertising or advertising analytics.

3. Device diagnostic information

Depending on the diagnostic feature selected by the user, GEL iDoctor may access device information such as hardware characteristics, operating-system information, storage and memory status, battery and thermal information, network state, Wi-Fi and Bluetooth information, sensor readings and application metadata.

These permissions are used only when required by the corresponding diagnostic feature and are subject to Android permission controls.

4. Camera, microphone and sensors

Certain manual diagnostic tests may request access to the camera, microphone, Bluetooth, nearby-device functions, location-related Android APIs or hardware sensors. These capabilities are used to perform the diagnostic test requested by the user.

5. Files and service reports

GEL iDoctor can generate diagnostic or service reports. When the user chooses to export a report, the resulting file may be stored on the device or shared using Android's standard sharing mechanisms.

6. Network, crash reporting and tester access

GEL iDoctor uses Google Firebase as a service provider. Firebase Crashlytics, including native crash reporting, collects crash logs, stack traces, diagnostic app state, app and operating-system versions, device metadata and installation identifiers. Firebase Sessions collects session identifiers and app-interaction metrics such as foreground time and session starts. We use these data to monitor reliability, diagnose failures and improve application performance. These reports are transmitted off the device and are not processed only ephemerally. Version 4.9 does not offer an in-app switch to disable this automatic reliability-data collection.

Tester PRO activation is optional. When a user enters a tester activation code, Firebase Authentication creates an anonymous user identifier (UID). Firebase Cloud Functions and Cloud Firestore use this identity and the activation code to validate and maintain tester access, including its status and expiry. Ordinary users do not need to activate Tester PRO to use the app's available features. The tester UID is retained for entitlement checks rather than processed only in memory. This flow does not ask for a name, email address, phone number or password. Anonymous authentication still creates a persistent pseudonymous identifier; it is not fully anonymized data.

Firebase Authentication also processes IP addresses and technical request information for authentication security and abuse prevention. Internet-based tests communicate with the relevant test endpoint, which necessarily receives the connection's IP address. The collection described above is distinct from diagnostic information that is processed solely on the device.

Remote Assistance is not available in the version 4.9 closed-test release. That release does not offer remote service sessions.

Further information about Firebase data processing is available in Firebase Privacy and Security and Firebase's Android data disclosures.

7. Service providers, advertising and sharing

Google Firebase processes the cloud data described above on our behalf to provide authentication, tester-entitlement and reliability services. Processing by a service provider is distinct from sharing data with independent third parties for their own purposes under Google Play's Data safety definitions.

GEL iDoctor does not sell user data or use installed-app inventory for advertising or advertising profiling. If you choose to export and share a report, the recipient and destination are selected by you through the available sharing mechanisms.

8. Data security

Firebase communications use HTTPS encryption in transit. Android permissions and platform security controls protect access to device capabilities and locally stored app data where applicable. No storage or transmission system can guarantee absolute security.

9. Data retention and deletion

Locally stored application data can be removed through Android's app-data controls or by uninstalling the app. Reports exported to shared storage, backups or recipients may remain outside the app; those copies must be managed separately.

Cloud crash and session reports are retained according to the applicable Firebase service retention settings and policies. Tester identity and entitlement records are retained as necessary to operate and verify tester access and to meet applicable obligations. We do not promise that all cloud data is deleted within 90 days. Clearing local data or uninstalling the app does not itself delete cloud records.

Users may contact the developer through the contact information on the Google Play listing to request deletion of personal data associated with GEL iDoctor. We may need information sufficient to identify the relevant records and verify the request. Do not send passwords or authentication tokens. Requests are handled subject to applicable obligations and the available controls of the relevant service provider.

10. Children's privacy

GEL iDoctor is a technical device-diagnostics application and is not designed specifically for children.

11. Changes to this policy

This Privacy Policy may be updated when GEL iDoctor functionality or applicable requirements change. The effective date shown at the top of this page identifies the current version.

12. Contact

Privacy-related inquiries can be directed to the developer using the developer contact information listed for GEL iDoctor on Google Play.
